# VoiceSphere Setup Guide

This repository contains a React Native mobile app (VoiceSphere). To set it up on your machine, follow these steps:

## Prerequisites
- Node.js and npm installed
- For iOS: Xcode and CocoaPods (`sudo gem install cocoapods`)
- For Android: Android Studio and Java Development Kit (JDK)

## Setup Instructions

### 1. Clone the Repository
```bash
git clone <repository-url>
cd VoiceSphere
```

### 2. Install JavaScript Dependencies
```bash
npm install
```
This will regenerate the `node_modules/` directory (8.3GB) which is not included in the repository.

### 3. Setup iOS (macOS only)
```bash
cd ios
pod install
cd ..
```
This will regenerate the `ios/Pods/` directory with all iOS native dependencies.

### 4. Setup Android
Open the `android/` folder in Android Studio, or run:
```bash
cd android
./gradlew clean
cd ..
```
This will download and configure all Android dependencies and build tools.

### 5. Run the App

**For iOS:**
```bash
npx react-native run-ios
```

**For Android:**
```bash
npx react-native run-android
```

## What's Not Included in This Repository

The following directories are excluded from Git because they can be regenerated:
- `node_modules/` (8.3GB) - JavaScript dependencies, regenerated by `npm install`
- `ios/Pods/` & `ios/build/` - iOS dependencies and build artifacts
- `android/build/`, `android/.gradle/` - Android build artifacts

These are listed in `.gitignore` and will be automatically created when you follow the setup steps above.

## Troubleshooting

If you encounter issues:
1. Make sure all prerequisites are installed
2. Try deleting `node_modules/` and running `npm install` again
3. For iOS: Delete `ios/Pods/` and run `pod install` again
4. For Android: Run `cd android && ./gradlew clean` and try again

For more details, check the main [README.md](README.md) and [SETUP_AND_TEST_GUIDE.md](SETUP_AND_TEST_GUIDE.md).
